# Glosario

- **API:** interfaz para que clientes intercambien solicitudes y respuestas con una aplicacion.
- **BSON:** representacion binaria de documentos que utiliza MongoDB.
- **Clave foranea:** restriccion relacional que enlaza una fila con otra tabla.
- **Coleccion:** agrupacion de documentos en MongoDB.
- **Documento:** registro tipo objeto con campos y valores; puede tener campos opcionales.
- **Indice:** estructura auxiliar para acelerar busquedas, con costo adicional de almacenamiento y escritura.
- **Monolito modular:** aplicacion desplegada como una unidad con modulos internos de responsabilidades diferenciadas.
- **No estructurado:** descripcion informal de contenido con forma menos tabular; aun requiere metadatos y criterios de validacion.
- **Notebook:** documento ejecutable que combina texto, codigo y resultados.
- **Persistencia:** almacenamiento que conserva datos mas alla de la ejecucion del proceso.
- **SQL:** lenguaje declarativo para consultar y modificar datos relacionales.
- **Esquema:** reglas y forma esperada de los datos, explicitas o implicitas.
